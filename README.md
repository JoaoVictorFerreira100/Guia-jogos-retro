RetroVerse — O Universo dos Jogos Retrô

Bem-vindo ao RetroVerse, um site dedicado aos melhores jogos retrô da história dos videogames!

O projeto apresenta jogos clássicos que marcaram gerações, reunindo informações sobre títulos famosos, consoles históricos e curiosidades sobre a evolução dos videogames.

Sobre o Projeto

O RetroVerse foi desenvolvido utilizando exclusivamente HTML, com o objetivo de criar um site simples, organizado e informativo sobre a história dos jogos retrô.

O conteúdo está dividido em diferentes seções, facilitando a navegação entre os jogos e consoles apresentados.

Conteúdo do Site

- Jogos Clássicos: conheça títulos que marcaram a história dos videogames.
- Nintendo: descubra grandes sucessos como Super Mario Bros. e Donkey Kong Country.
- SEGA: relembre jogos como Sonic the Hedgehog e Streets of Rage.
- Fliperamas: conheça clássicos como Pac-Man, Galaga e Street Fighter II.
- RPGs Retrô: explore jogos como Pokémon Red e Blue e Chrono Trigger.
- Jogos de Terror: relembre clássicos como Resident Evil.
- Jogos de Corrida: conheça títulos como Top Gear e Mario Kart 64.
- Jogos de Plataforma: descubra aventuras como Mega Man 2 e Rayman.
- Consoles Históricos: conheça sistemas como NES, Super Nintendo, Mega Drive e PlayStation.
- Curiosidades: descubra fatos interessantes sobre os jogos antigos.
- Recomendações: encontre sugestões para começar sua jornada pelo universo retrô.

Tecnologias Utilizadas

- HTML5

O projeto utiliza apenas HTML, sem dependências de CSS ou JavaScript.

Como Executar

1. Baixe ou clone este repositório.
2. Localize o arquivo "index.html".
3. Abra o arquivo em um navegador, como Google Chrome ou Microsoft Edge.
4. Navegue pelas seções e explore o conteúdo.

Não é necessário instalar programas adicionais para visualizar o site.

Objetivos do Projeto

- Praticar a criação de páginas utilizando HTML.
- Aprender a organizar conteúdos em seções.
- Desenvolver uma página com links de navegação internos.
- Compartilhar informações sobre a história dos videogames.
- Criar um projeto que possa ser utilizado como parte de um portfólio de desenvolvimento web.

Possíveis Melhorias Futuras

- Adicionar cores e um layout personalizado com CSS.
- Inserir imagens dos jogos e consoles.
- Criar uma seção com os jogos favoritos dos visitantes.
- Melhorar a experiência de navegação em dispositivos móveis.
- Adicionar recursos interativos utilizando JavaScript.

Observações

Este projeto tem finalidade educativa e informativa. Os nomes dos jogos, personagens e consoles mencionados pertencem aos seus respectivos titulares.

Autor
